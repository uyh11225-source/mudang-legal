개인정보처리방침

시행일: 2026년 11월 7일

CORDAPPS(이하 “운영자”)는 무당들(이하 “서비스”)에서 처리하는 개인정보를 다음과 같이 안내합니다. 서비스는 AI 기반 운세 및 가상 상담 콘텐츠입니다.

1. 처리하는 정보와 목적

계정·인증Supabase Auth 사용자 ID, 이메일(제공되는 경우), 로그인 제공자 식별 정보, 인증 과정에서 제공되는 프로필 메타데이터. 이메일 가입 또는 Google·Naver 로그인을 통한 인증과 계정 관리에 이용합니다. 프로필 표시 이름은 계정 생성 때 제공된 표시 이름 또는 이메일 앞부분을 기본값으로 저장할 수 있습니다. 프로필 사진은 실제 전송·저장 범위가 배포 설정에 따라 달라질 수 있어 별도 확인이 필요합니다.
운세 입력·결과이용자가 입력하는 이름, 생년월일·출생 시각, 성별, 음력·양력 구분, 관계·가족 정보, 질문·고민·꿈 내용 및 분석 결과. 운세·사주 등 요청한 기능 제공과 결과 저장·조회에 이용합니다.
상담AI 가상 상담 메시지·응답, 세션 및 이용자가 허용한 과거 운세 정보 참조 내역. 상담 제공과 기록 조회에 이용합니다.
사진·이미지이용자가 사진 분석을 위해 선택·제출한 이미지와 분석 결과, 부적 생성 요청의 소원 문구 및 결과 이미지. 요청된 분석·생성 기능을 제공하기 위해 처리합니다.
서비스·결제 기록포인트 잔액·변동·이용 기록, 서비스 처리 상태와 시각, Google Play 구매 확인에 필요한 상품·주문·구매 토큰 관련 정보. 서비스 제공, 장애 대응 및 구매 검증에 이용합니다.
문의·삭제 요청문의에 포함한 이메일과 내용, 삭제 요청 처리에 필요한 계정 식별·처리 상태. 문의 답변과 삭제 요청 처리에 이용합니다.

2. 수집 방법

회원 가입·로그인, 앱에서 이용자가 직접 입력·선택한 정보와 기능 사용 기록, Google Play 구매 확인, 이메일 문의를 통해 처리합니다. 사진은 이용자가 해당 기능에서 선택해 제출할 때 처리됩니다.

3. 처리 위탁·외부 서비스

  • Supabase: 인증 및 데이터베이스 처리·저장.
  • Google 및 Naver: 이용자가 선택한 소셜 로그인 인증. Google Play는 인앱 결제 처리·구매 검증.
  • OpenAI: 요청한 AI 운세·상담·사진 분석·이미지 생성에 필요한 입력, 대화, 이미지 또는 소원 문구가 API 요청에 포함될 수 있습니다.
  • Contabo 운영 API 서버: 서비스 API 처리 및 생성 부적 등 서버 파일 처리·보관.
  • GitHub Pages: 본 안내 웹페이지 제공. 이 페이지 자체는 앱 로그인 정보 입력 폼을 제공하지 않습니다.

각 외부 제공자의 실제 처리 위치, 보유 기간, 재위탁 및 삭제 조건은 운영 계정 설정과 각 서비스 약관에 따릅니다. 국가별 이전 위치와 법적 근거는 현재 저장소 자료만으로 전부 검증할 수 없어 확정 기재하지 않습니다. 처리 위탁 계약·설정 및 국외 이전 고지 여부를 운영자가 확인해 보완해야 합니다.

4. 보유 및 삭제

계정 정보와 서비스 이용 데이터는 계정 이용 및 서비스 제공을 위해 보관합니다. 앱 MY/설정의 “회원 탈퇴”를 실행하면 앱이 인증된 요청을 서버로 보내며, 서버는 본인 계정의 Auth 사용자를 삭제하고 연결 프로필 및 종속 데이터의 연쇄 삭제를 요청합니다. 생성 중인 부적이 있으면 삭제가 거절될 수 있습니다. 운영 서버에 저장된 해당 이용자의 부적 이미지와 생성 이력도 삭제 절차에 포함됩니다.

Google Play 구매 증빙은 계정 삭제를 막지 않습니다. 저장소 마이그레이션은 결제 행의 사용자 연결을 해제하여 잔존시킬 수 있도록 구성되어 있습니다. 실제 보유 항목별 법정 보유 기간은 확인 가능한 저장소 자료에 정해져 있지 않으므로 여기서 임의로 기간을 단정하지 않습니다. 보유 법적 근거·기간·관리 절차를 확인해 공개 전에 확정해야 합니다.

외부 AI·로그인·호스팅 사업자에게 이미 전달된 정보, 기기에 저장·다운로드한 파일 또는 타인에게 공유된 사본이 계정 삭제와 동시에 모두 삭제된다고 보장하지 않습니다. 관련 요청은 아래 문의처로 접수할 수 있습니다.
